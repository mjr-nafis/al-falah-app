গুগল শিট লাইভ ক্লাউড সংযোগ

Apps Script API দিয়ে রিয়েল-টাইম ২-ওয়ে সিঙ্ক

লোকাল মোডে চলছে (অফলাইন)

গুগল শিট লাইভ ক্লাউডের সাথে যুক্ত করতে নিচের বক্সে Apps Script Web App URL টি দিন।

গুগল শিটের Extensions > Apps Script > Deploy > New deployment (Web app) থেকে পাওয়া লিঙ্ক।

সহজ ৪ ধাপের সংযোগ নির্দেশিকা:

  1. গুগল শিটে গিয়ে মেনু থেকে Extensions > Apps Script-এ যান।
  2. আমাদের দেওয়া GoogleAppsScript_Code.gs কোডটি পেস্ট করে সেভ করুন।
  3. উপরে Deploy > New deployment এ গিয়ে Type হিসেবে Web app বাছুন।
  4. Who has access: "Anyone" দিয়ে Deploy চাপুন এবং Web App URL কপি করে এখানে পেস্ট করুন।
